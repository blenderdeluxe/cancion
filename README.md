# Canción para sentir

Página sin audio: vibra la melodía en el celular (Chrome Android) e ilumina letra y onda al ritmo.

- Uso: abrir en el móvil y tocar **Sentir la melodía** (la vibración necesita un toque del usuario).
- `index.html` es autocontenida: sin dependencias, sin backend, sin CDN.
- Publicada con GitHub Pages.
