# Canciones para sentir

Página **sin audio**: el teléfono vibra la melodía en la mano y la letra se ilumina al ritmo.
Nació para cuando alguien olvida los audífonos: la música se puede **ver** (letra + onda) y
**sentir** (vibración), sin que suene nada.

Abrir en Chrome de Android y tocar **Sentir**: la vibración necesita un toque del usuario.
En iPhone ningún navegador permite vibrar desde una web, pero la melodía igual se lee y se anima.

Cómo se siente: cada nota vibra distinto según su altura (grave = un pulso largo y suave;
aguda = varios pulsos cortos seguidos), así se nota la melodía subir y bajar.

## Repertorio

**Clásicas**
- Estrellita — melodía anónima del s. XVIII (dominio público)

**Navidad**
- Noche de paz (Mohr / Gruber, 1818 — dominio público)
- Navidad, Navidad («Jingle Bells», 1857 — dominio público)
- Campana sobre campana — villancico popular español del s. XIX (dominio público)

**Reggaetón**
- El dembow — patrón rítmico genérico del género: bombo en los cuatro tiempos y caja en el 3+3+2
- La noche entera — letra y melodía originales escritas para esta página

## Notas

- `index.html` es autocontenida: sin dependencias, sin backend, sin CDN.
- Del reggaetón no hay letras ni melodías de canciones comerciales: en una página pública eso
  no se puede usar (obra de autores vivos). Se usan el patrón rítmico del género y una canción
  propia.
- Los datos de cada frase se validan antes de generar: el número de sílabas tiene que ser igual
  al número de notas, o la letra y la onda se desalinean.
- Publicada con GitHub Pages.
